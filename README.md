# Telegram-бот с тарифами и оплатой

Python 3.11, aiogram 3.

## Файлы
- `main.py` — запуск бота и веб-сервера
- `config.py` — настройки из переменных окружения
- `handlers.py` — команды и кнопки
- `database.py` — SQLite
- `payments.py` — создание платежа и проверка подписи вебхука (подогнать под платёжку)
- `webhook.py` — приём уведомлений об оплате
- `.env` — ключи (не выкладывать в публичный репозиторий)

## Команды
- `/start` — список тарифов
- `/addtariff`, `/tariffs`, `/deltariff ID` — только для админа

## Запуск на Bothost
1. Создать проект, загрузить все файлы (или подключить приватный GitHub-репозиторий).
2. Загрузить `.env` кнопкой «Загрузить из файла .env».
3. Команда запуска: `python main.py`.
4. Когда появится адрес бота — вписать его в `PUBLIC_URL`.
